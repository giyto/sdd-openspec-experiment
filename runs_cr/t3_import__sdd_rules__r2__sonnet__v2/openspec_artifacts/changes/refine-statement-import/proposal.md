## Why

Импорт выписок из LEDGER-58 проработал месяц, и выяснилось следующее: «Сфера» сменила формат сумм (десятичная точка), служебные операции банка (нули в обеих колонках) ошибочно считаются ошибками, описания приходят с лишними пробелами и переводами строк, строгий режим вынуждает исправлять файл по одной ошибке за запуск, а интерфейсу импорта нужны превью и тексты ошибочных записей.

## What Changes

- «Сфера» (`sfera` и `sfera_split`): десятичным разделителем суммы может быть и запятая, и точка (`-1 234.56`, `-1 234,56`); сумма, где есть и точка, и запятая, — ошибка строки. Ранее точка была ошибкой. **BREAKING** для файлов, где точка считалась ошибкой.
- `sfera_split`: строка с явными нулями в обеих колонках (`0,00`/`0.00`/`0`) молча пропускается — не ошибка, не дубль, не добавление. Ранее — ошибка. Ноль в одной колонке при пустой второй по-прежнему ошибка. **BREAKING** для этого случая.
- Описание сохраняется без лишних пробельных символов: по краям обрезается, любая последовательность пробельных символов (пробелы, табы, переводы строк, ` ` и т. п.) внутри заменяется одним пробелом; регистр и буквы не меняются. Относится ко всем форматам.
- Строгий режим разбирает файл до конца и бросает `StatementRowError` со всеми ошибками строк (`errors: list[RowError]`); `line_no` и сообщение — от первой ошибки. Атомарность прежняя. **BREAKING**: ранее разбор останавливался на первой ошибке.
- `import_statement(path, store, *, fmt=None, strict=False, categorizer=None, clock=None, dry_run=False) -> ImportResult`: новый параметр `dry_run` — превью без записи в хранилище.
- `ImportResult.transactions: list[Transaction]` — добавленные (в `dry_run` — добавляемые, с `id=None`) транзакции в порядке строк файла.
- `RowError.raw: str = ""` — текст записи из файла (раскодированный, без BOM и `\r`, строки многострочной записи соединены через `\n`, без завершающего перевода строки).
- `StatementRowError.errors: list[RowError]` в `ledger/errors.py`.

### New Capabilities

### Modified Capabilities
- `statement-import`: изменяются правила разбора сумм «Сферы», обработка нулевых строк `sfera_split`, нормализация описания, строгий режим (все ошибки), сигнатура `import_statement`, поля `RowError` и `ImportResult`; добавляются превью `dry_run` и `raw` ошибок.

## Impact

- Код: `ledger/importer.py`, `ledger/errors.py`. `ledger/cli.py`, `ledger/reports.py` не трогаем; только стандартная библиотека.
- API: `import_statement` получает keyword-only `dry_run` в конце; `ImportResult` и `RowError` расширяются полями с умолчаниями; `StatementRowError` получает `errors`. Старые вызовы `import_statement`/`import_csv` работают как раньше, кроме пунктов выше.
- Тесты: обновить только тесты LEDGER-58, проверявшие изменённое поведение (точка в сумме «Сферы», нули в обеих колонках `sfera_split`, обрезка описания, strict на первой ошибке); остальные существующие тесты не менять.
- `RowError` определяется в `ledger/errors.py` (иначе циклический импорт) и реэкспортируется из `ledger.importer`, так что `from ledger.importer import RowError` продолжает работать.
