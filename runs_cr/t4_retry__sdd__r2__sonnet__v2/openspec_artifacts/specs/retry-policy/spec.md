# retry-policy Specification

## Purpose
Описывает политику повторов: параметры и их проверку, расчёт задержки с экспоненциальным ростом, классификацию ошибок на повторяемые и неповторяемые, а также назначение политики очереди и типу задания.

## Requirements

### Requirement: Параметры политики и их значения по умолчанию
Политика повторов SHALL быть неизменяемым объектом с параметрами: `max_attempts` (всего попыток, включая первую; по умолчанию 3), `base_delay` (секунды; 1.0), `factor` (2.0), `max_delay` (секунды; 60.0), `jitter` (от 0 до 1; 0.0), `non_retryable` (классы исключений; по умолчанию пусто). Переданный в `non_retryable` список SHALL храниться как кортеж.

#### Scenario: Значения по умолчанию
- **WHEN** создаётся политика без аргументов
- **THEN** `max_attempts=3`, `base_delay=1.0`, `factor=2.0`, `max_delay=60.0`, `jitter=0.0`, `non_retryable=()`

#### Scenario: Список превращается в кортеж
- **WHEN** в `non_retryable` передан список `[ValueError]`
- **THEN** значение параметра равно `(ValueError,)`

### Requirement: Проверка параметров политики
Некорректные параметры SHALL приводить к ошибке конфигурации (`ConfigError`) при создании политики: `max_attempts < 1`, `base_delay < 0`, `factor < 1`, `max_delay < base_delay`, `jitter` вне `[0, 1]`, элемент `non_retryable`, не являющийся классом исключения. Нечисловые значения и NaN SHALL отвергаться так же. Граничные значения (`max_attempts=1`, `base_delay=0`, `factor=1`, `max_delay == base_delay`, `jitter` 0 и 1) SHALL быть допустимы.

#### Scenario: Недопустимые значения
- **WHEN** создаётся политика с `max_attempts=0`, либо `base_delay=-1`, либо `factor=0.5`, либо `max_delay` меньше `base_delay`, либо `jitter=1.5`
- **THEN** выбрасывается ошибка конфигурации

#### Scenario: Элемент non_retryable не класс исключения
- **WHEN** в `non_retryable` передан экземпляр исключения, не-исключение или класс, не наследующий `BaseException`
- **THEN** выбрасывается ошибка конфигурации

#### Scenario: Граничные значения
- **WHEN** создаётся политика с `max_attempts=1`, `base_delay=0`, `factor=1`, `jitter=1`
- **THEN** ошибки нет

### Requirement: Расчёт задержки перед повтором
Расчёт задержки для упавшей попытки номер `attempt` (нумерация с 1) SHALL возвращать `base_delay * factor ** (attempt - 1)`, ограниченное сверху `max_delay`. При `jitter > 0` уже ограниченная задержка SHALL умножаться на одно значение `rng.uniform(1 - jitter, 1 + jitter)`, после чего результат SHALL снова ограничиваться сверху `max_delay` и снизу нулём. Результат SHALL всегда лежать в `[0, max_delay]`. Расчёт SHALL работать для любого `attempt >= 1`, включая очень большие значения (например 5000 при `factor=2.0` или 10**9), и при `base_delay=0`, без переполнения и без NaN. При `jitter == 0` генератор случайных чисел SHALL не использоваться. Если генератор не передан, а `jitter > 0`, SHALL использоваться общий генератор модуля `random`. При `attempt < 1` SHALL выбрасываться ошибка конфигурации.

#### Scenario: Экспоненциальный рост
- **WHEN** политика `base_delay=1, factor=2, max_delay=60`, jitter 0
- **THEN** задержки для попыток 1, 2, 3, 4 равны 1, 2, 4, 8 секунд

#### Scenario: Потолок
- **WHEN** вычисленная задержка превышает `max_delay`
- **THEN** возвращается ровно `max_delay`

#### Scenario: Огромный номер попытки
- **WHEN** запрошена задержка для попытки 5000 (или 10**9) при `factor=2.0`
- **THEN** возвращается `max_delay`, исключений нет

#### Scenario: Нулевая базовая задержка
- **WHEN** `base_delay=0` и попытка очень большая
- **THEN** возвращается 0.0

#### Scenario: Джиттер не пробивает потолок
- **WHEN** `jitter=0.5`, задержка до джиттера равна `max_delay`, а генератор вернул множитель больше 1
- **THEN** результат не превышает `max_delay`

#### Scenario: Один вызов генератора на задержку
- **WHEN** `jitter > 0`
- **THEN** генератор вызывается ровно один раз как `uniform(1 - jitter, 1 + jitter)`

#### Scenario: Без джиттера генератор не трогается
- **WHEN** `jitter == 0` и передан генератор
- **THEN** его состояние не меняется

#### Scenario: Попытка меньше единицы
- **WHEN** запрошена задержка для `attempt=0`
- **THEN** выбрасывается ошибка конфигурации

### Requirement: Классификация ошибок
Проверка повторяемости ошибки SHALL возвращать `False` для исключений, являющихся экземплярами любого класса из `non_retryable` (с учётом наследования), и всегда для `PermanentJobError` (в том числе его наследников), независимо от настроек. Для остальных исключений SHALL возвращаться `True`. `PermanentJobError` SHALL наследоваться от базовой ошибки пакета.

#### Scenario: Наследники неповторяемого класса
- **WHEN** `non_retryable=(ValueError,)` и обработчик бросил наследника `ValueError`
- **THEN** ошибка неповторяемая

#### Scenario: PermanentJobError
- **WHEN** обработчик бросил `PermanentJobError`, а `non_retryable` пуст
- **THEN** ошибка неповторяемая

### Requirement: Назначение политики очереди и типу задания
Очередь SHALL принимать политику по умолчанию при создании (только именованным параметром) и позволять назначать политику отдельному типу задания; назначение `None` SHALL снимать политику типа. Действующей политикой типа SHALL быть политика типа, если она назначена, иначе политика по умолчанию, иначе её нет. Политика типа SHALL заменять политику по умолчанию целиком, без слияния по полям. Значение, не являющееся политикой или `None`, SHALL вызывать ошибку конфигурации. Если политик нет, поведение очереди SHALL совпадать с поведением до этого изменения.

#### Scenario: Приоритет политики типа
- **WHEN** задана политика по умолчанию и политика для типа `email`
- **THEN** для `email` действует политика типа, для остальных типов — политика по умолчанию

#### Scenario: Замена целиком
- **WHEN** политика по умолчанию имеет `non_retryable=(ValueError,)`, а политика типа создана без `non_retryable`
- **THEN** для этого типа `ValueError` повторяемая

#### Scenario: Снятие политики типа
- **WHEN** политике типа назначено `None`
- **THEN** для типа снова действует политика по умолчанию, а при её отсутствии политики нет

#### Scenario: Неверный тип значения
- **WHEN** в качестве политики передана строка
- **THEN** выбрасывается ошибка конфигурации
