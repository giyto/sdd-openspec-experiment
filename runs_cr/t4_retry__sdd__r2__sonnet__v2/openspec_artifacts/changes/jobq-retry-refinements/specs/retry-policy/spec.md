## MODIFIED Requirements

### Requirement: Расчёт задержки перед повтором
Расчёт задержки для упавшей попытки номер `attempt` (нумерация с 1) SHALL возвращать `base_delay * factor ** (attempt - 1)`, ограниченное сверху `max_delay`. При `jitter > 0` уже ограниченная задержка SHALL умножаться на одно значение `rng.uniform(1 - jitter, 1)`, то есть джиттер только уменьшает задержку и никогда не увеличивает её; результат SHALL по-прежнему ограничиваться сверху `max_delay` и снизу нулём. Результат SHALL всегда лежать в `[0, max_delay]`. Расчёт SHALL работать для любого `attempt >= 1`, включая очень большие значения (например 5000 при `factor=2.0` или 10**9), и при `base_delay=0`, без переполнения и без NaN. При `jitter == 0` генератор случайных чисел SHALL не использоваться. Если генератор не передан, а `jitter > 0`, SHALL использоваться общий генератор модуля `random`. При `attempt < 1` SHALL выбрасываться ошибка конфигурации.

#### Scenario: Экспоненциальный рост
- **WHEN** политика `base_delay=1, factor=2, max_delay=60`, jitter 0
- **THEN** задержки для попыток 1, 2, 3, 4 равны 1, 2, 4, 8 секунд

#### Scenario: Потолок
- **WHEN** вычисленная задержка превышает `max_delay`
- **THEN** возвращается ровно `max_delay`

#### Scenario: Огромный номер попытки
- **WHEN** запрошена задержка для попытки 5000 (или 10**9) при `factor=2.0`
- **THEN** возвращается `max_delay`, исключений нет

#### Scenario: Нулевая базовая задержка
- **WHEN** `base_delay=0` и попытка очень большая
- **THEN** возвращается 0.0

#### Scenario: Джиттер не пробивает потолок
- **WHEN** `jitter=0.5`, расчётная задержка равна 10, а генератор вернул верхнюю границу диапазона
- **THEN** результат равен 10: ни расчётную задержку, ни `max_delay` он не превышает

#### Scenario: Джиттер уменьшает задержку
- **WHEN** `jitter=0.5`, расчётная задержка равна 10, а генератор вернул нижнюю границу диапазона
- **THEN** результат равен 5

#### Scenario: Один вызов генератора на задержку
- **WHEN** `jitter > 0`
- **THEN** генератор вызывается ровно один раз как `uniform(1 - jitter, 1)`

#### Scenario: Без джиттера генератор не трогается
- **WHEN** `jitter == 0` и передан генератор
- **THEN** его состояние не меняется

#### Scenario: Попытка меньше единицы
- **WHEN** запрошена задержка для `attempt=0`
- **THEN** выбрасывается ошибка конфигурации
