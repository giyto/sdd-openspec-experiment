## Why

Импорт выписок (LEDGER-58) проработал месяц, и выяснилось: «Сфера» сменила формат сумм (десятичная точка), служебные строки-блокировки в `sfera_split` ломают импорт, интерфейсу нужны превью без записи и сами строки с ошибками, а строгий режим заставляет чинить файл по одной ошибке за запуск (LEDGER-74).

## What Changes

- Суммы «Сферы» (`sfera`, `sfera_split`) принимают и запятую, и точку как десятичный разделитель; и точка, и запятая в одной сумме — ошибка строки. **BREAKING** для точки: раньше это была ошибка строки.
- `sfera_split`: строка с явными нулями в обеих колонках молча пропускается (не ошибка, не дубль, не добавление). **BREAKING**: раньше — ошибка строки.
- Описание сохраняется нормализованным по пробелам: обрезка по краям, любая последовательность пробельных символов (включая переводы строк и табы) внутри → один пробел; регистр и буквы не меняются. Действует для всех форматов, включая `nova` и `import_csv`.
- Строгий режим разбирает файл до конца и бросает `StatementRowError` со всеми ошибками (`errors`); `line_no` и сообщение — у первой. Атомарность прежняя. **BREAKING** для тех, кто полагался на остановку на первой ошибке (набор `errors` теперь полный, `line_no` прежний).
- `import_statement(..., dry_run=False)`: при `dry_run=True` всё считается как при настоящем импорте, но в хранилище ничего не пишется.
- `ImportResult.transactions`: добавленные (при `dry_run` — были бы добавлены) транзакции в порядке строк файла; `id` назначает хранилище, при `dry_run` они `None`.
- `RowError.raw`: исходный текст записи из файла (раскодированный, без BOM, `\r` и конечного перевода строки; многострочная запись соединяется через `\n`).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `statement-import`: изменяются требования к разбору сумм «Сферы», разбору `sfera_split`, формату «Нова» (описание), нестрогому и строгому режимам, результату импорта, категоризации и метаданным, совместимости `import_csv`; добавляется требование о превью (`dry_run`).

## Impact

- Код: `ledger/importer.py`, `ledger/errors.py` (`RowError` определяется в `errors.py` и реэкспортируется из `importer.py`, чтобы избежать циклического импорта). `ledger/cli.py`, `ledger/reports.py` и существующие тесты вне пунктов 1–4 не затрагиваются.
- Тесты `tests/test_statement_import.py` (и `tests/test_importer.py`, если там есть описания с лишними пробелами) с прежним поведением пунктов 1–4 обновляются.
- `README.md`: раздел про выписки.
- Зависимости: только стандартная библиотека. Уже сохранённые транзакции не мигрируются.
