## Why

Пользователи приносят выписки банка «Сфера», а ledger умеет только «Нову». Текущий `import_csv` к тому же хрупкий: повторный импорт задваивает операции, одна кривая строка роняет импорт на середине (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются (LEDGER-58).

## What Changes

- Новая точка входа `import_statement(path, store, *, fmt, strict, categorizer, clock) -> ImportResult` в `ledger/importer.py`, а также `detect_format`, `normalize_description`, `RowError`, `ImportResult`.
- Форматы: `nova` (как сейчас), `sfera` (`Дата;Сумма;Описание`), `sfera_split` (`Дата;Описание;Приход;Расход`); формат определяется по заголовку (колонки по имени, без учёта регистра и краевых пробелов, лишние колонки игнорируются, порядок любой).
- Кодировка: UTF-8 (с BOM или без), иначе cp1251.
- Дедупликация по (дата, сумма, `normalize_description`) относительно содержимого хранилища до импорта, с учётом количества.
- Кривые строки не роняют импорт: попадают в `ImportResult.errors`; при `strict=True` — `StatementRowError` на первой, и в хранилище не попадает ничего. Мусорные строки (пустые, из пробелов, из одних разделителей) пропускаются молча.
- Атомарность: все новые транзакции записываются одним `add_many`.
- Новые исключения `UnknownFormatError`, `StatementRowError` (наследники `StatementError`).
- `import_csv` становится обёрткой: строгий импорт `nova` через `import_statement`, возвращает число добавленных. **Изменение поведения** для CLI (без правок `cli.py`): повторный импорт больше не задваивает, BOM/cp1251 читаются, пустые строки пропускаются.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских CSV-выписок (nova, sfera, sfera_split): определение формата и кодировки, разбор строк, дедупликация, отчёт об ошибках, строгий режим и атомарность, совместимая обёртка `import_csv`.

(нет: в `openspec/specs/` пока нет спецификаций)

## Impact

- Код: `ledger/importer.py` (основное), `ledger/errors.py` (два класса). `ledger/cli.py`, `ledger/reports.py` не меняются.
- API: `Transaction`, хранилища, `Categorizer` не меняются; только стандартная библиотека. Сигнатура `import_csv` прежняя.
- Тесты: существующие не меняются (остаются зелёными, см. design), добавляются новые.
