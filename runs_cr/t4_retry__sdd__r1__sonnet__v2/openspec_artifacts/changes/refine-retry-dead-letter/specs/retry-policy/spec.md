## MODIFIED Requirements

### Requirement: Джиттер
При `jitter > 0` уже ограниченная задержка SHALL умножаться на `rng.uniform(1 - jitter, 1)`, то есть джиттер только уменьшает задержку и результат никогда не превышает расчётную задержку. Результат SHALL по-прежнему ограничиваться `max_delay` сверху и нулём снизу (защита от значений генератора вне диапазона). На один расчёт задержки SHALL приходиться ровно один вызов `uniform`. При `jitter == 0` генератор SHALL NOT вызываться. Если `rng` не передан, SHALL использоваться генератор модуля `random`.

#### Scenario: Предсказуемый джиттер
- **WHEN** `jitter=0.5`, `base_delay=10`, `rng.uniform` возвращает 0.75
- **THEN** `delay_for(1)` равна 7.5, `uniform` вызван один раз с аргументами `(0.5, 1)`

#### Scenario: Джиттер не пробивает потолок
- **WHEN** `jitter=1`, задержка равна `max_delay`, а `rng.uniform` возвращает значение больше 1 (например, 2.0)
- **THEN** результат не больше расчётной задержки и не больше `max_delay`

#### Scenario: Неотрицательный результат
- **WHEN** `rng.uniform` возвращает отрицательное значение
- **THEN** результат равен 0.0

#### Scenario: Без джиттера генератор не трогается
- **WHEN** `jitter=0` и передан `rng`
- **THEN** `rng` не вызывается
