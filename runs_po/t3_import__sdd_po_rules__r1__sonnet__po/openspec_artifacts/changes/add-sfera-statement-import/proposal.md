## Why

Пользователи приносят выписки банка «Сфера», а импорт умеет только «Нову». Текущий `import_csv` к тому же хрупкий: повторный импорт задваивает операции, одна кривая строка роняет импорт посреди файла (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются. Задача LEDGER-58.

## What Changes

- Новый единый вход `import_statement(path, store, *, fmt=None, strict=False, categorizer=None, clock=None) -> ImportResult` в `ledger/importer.py`.
- Новые функции `detect_format(path) -> str` (`"nova"` | `"sfera"` | `"sfera_split"`) и `normalize_description(text: str) -> str`.
- Новые frozen-датаклассы `RowError(line_no, message)` и `ImportResult(format, encoding, added, duplicates, errors)`.
- Новые исключения в `ledger/errors.py`: `UnknownFormatError(StatementError)` и `StatementRowError(StatementError)` (с заполненным `line_no`).
- Поддержка форматов «Сферы»: `sfera` (`Дата;Сумма;Описание`) и `sfera_split` (`Дата;Описание;Приход;Расход`), помимо `nova`. Нужные колонки ищутся по названию без учёта регистра и пробелов по краям; лишние колонки (`Номер карты`, `Остаток`) игнорируются. В `sfera_split` `0,00` в одной из колонок `Приход`/`Расход` равно пустой колонке.
- Определение кодировки: UTF-8 (BOM допустим), иначе cp1251.
- Пропуск дублей со счётчиком `duplicates`: повтором считается только то, что уже лежало в хранилище до импорта (дата + сумма + описание после `normalize_description`), с учётом количества: если в хранилище одна такая операция, а в файле три, то одна строка файла — дубль, две добавляются.
- Пустые, пробельные и «из одних разделителей» строки пропускаются молча, где бы ни стояли.
- Кривые строки собираются в `errors` и не мешают остальным; при `strict=True` первая кривая строка даёт `StatementRowError`, и в хранилище не попадает ничего.
- `import_csv(path, store, categorizer=None, clock=None) -> int` сохраняет сигнатуру и тип результата и становится тонкой обёрткой над `import_statement` (`strict=True`); CLI на нём продолжает работать без изменений.
- **Поведенческое изменение `import_csv`/CLI** (существующие тесты не ломает) ограничено перечисленным: повторный импорт не задваивает операции, ошибка строки не оставляет частично записанных данных, файл с BOM и cp1251 читается, пустые строки пропускаются, форматы «Сферы» распознаются автоматически. Всё остальное для загрузки «Новы» остаётся как раньше, включая приём строк с непустыми лишними полями.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских выписок (`nova`, `sfera`, `sfera_split`): определение формата и кодировки, разбор строк, дубли, мусорные строки, ошибки строк, строгий режим, совместимая обёртка `import_csv`.

## Impact

- Код: `ledger/importer.py`, `ledger/errors.py`; новые тесты (существующие не меняются); раздел про импорт в `README.md`.
- Не трогаем: `ledger/cli.py`, `ledger/reports.py`. Публичный API `Transaction`, хранилищ и `Categorizer` не меняется.
- Зависимости: только стандартная библиотека.
