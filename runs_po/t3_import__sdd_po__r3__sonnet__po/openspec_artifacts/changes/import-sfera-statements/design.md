## Context

Сейчас `ledger/importer.py` читает только «Нову» через `csv.DictReader` и пишет транзакции по одной (`store.add`) — отсюда частичная запись при ошибке. В `MemoryStore`/`JsonFileStore` уже есть `add_many` — всё-или-ничего, одна запись на диск. Сравнение описаний в проекте — `rules.normalize_text`. Нумерация строк — по `StatementError`. Мотивация — см. proposal.md.

## Goals / Non-Goals

**Goals:** один путь импорта для всех форматов; атомарная запись; детерминированный отчёт.

**Non-Goals:** правки `cli.py`, `reports.py`, моделей и хранилищ; вывод `ImportResult` в CLI; новые зависимости.

## Decisions

1. **Конвейер «разобрать всё → решить → записать одной пачкой».** Разбираем весь файл в память по порядку, собираем новые транзакции, ошибки и счётчик дублей. Если `strict` и есть ошибка — бросаем `StatementRowError` для первой до обращения к записи. Иначе один вызов `store.add_many(new)`; при пустом списке не вызываем, чтобы не создавать JSON-файл зря. Альтернатива — `add` по строке с откатом: у хранилищ отката нет.
2. **Кодировка:** читаем байты; `decode("utf-8-sig")`, при `UnicodeDecodeError` — `decode("cp1251")`; если и это падает (недопределённые байты) — `UnknownFormatError`. В результате имя `utf-8` либо `cp1251`.
3. **Текст → записи:** `csv.reader(io.StringIO(text, newline=""), delimiter=...)`; начало записи = `reader.line_num` до чтения + 1, что даёт физические номера с учётом пустых строк и многострочных кавычек. `csv.Error` на записи → `RowError` на этой строке, чтение продолжается.
4. **Формат по заголовку:** первая запись, ячейки `strip().casefold()`. Для каждого формата свой разделитель (`nova` — `,`, «Сфера» — `;`); заголовок разбирается обоими и в каждом ищутся нужные колонки по названию — в любом порядке, лишние допускаются и не читаются. Результат — отображение «колонка → индекс». При дубле названия берётся первая колонка. Если без явного `fmt` подходят и `sfera`, и `sfera_split` — заголовок нераспознан (не угадываем); при явном `fmt` проверяется только он. Строка данных ошибочна, если в ней нет поля с индексом какой-либо нужной колонки («not enough fields»); лишние поля и недостающие ненужные колонки ошибкой не являются — для всех форматов, включая `nova`. `detect_format` и `import_statement` используют одну внутреннюю функцию. Неизвестное значение `fmt` → `UnknownFormatError`.
5. **Мусор:** запись мусорная, если после удаления из всех ячеек пробельных символов (включая U+00A0), `;` и `,` ничего не остаётся. Проверка раньше разбора, поэтому `,,` в файле «Сферы» и `;;;` в «Нове» тоже мусор.
6. **Суммы «Сферы»:** регулярка `^[+-]?(\d{1,3}([   ]\d{3})+|\d+)(,\d{1,2})?$` (для `sfera_split` — без знака; пробелы-разделители — обычный и U+00A0), затем пробелы убираются, `,`→`.` и вызывается `parse_amount`. Для `sfera_split` значение колонки: пустое (после `strip`) — пусто; иначе проверяется регулярка без знака, и ноль (`0,00`) тоже считается пустой колонкой; ненулевой должна быть ровно одна колонка, иначе ошибка строки (обе ненулевые или обе пустые/нулевые). Ноль в `sfera`, пустое описание и т.п. ловятся конструктором `Transaction`; `ValidationError` → ошибка строки. Даты «Сферы» — строго `ДД.ММ.ГГГГ`, «Новы» — как раньше `fromisoformat`. Минус U+2212 и точка как десятичный разделитель не принимаются — строка ошибочна (честнее, чем угадывать).
7. **Дедупликация — мультимножество:** ключ `(date, amount, normalize_description(description))`; `Counter` по снимку `store.all()` до импорта, каждое совпадение уменьшает счётчик. Повторный импорт идемпотентен, а две реальные одинаковые покупки в одном файле не склеиваются. Альтернатива «множество» теряла бы легитимные операции.
8. **`normalize_description`** — тонкая обёртка над `rules.normalize_text` (единый источник правды; `importer` уже импортирует `rules`).
9. **Исключения:** `UnknownFormatError(StatementError)`; `StatementRowError(StatementError)` с обязательным `line_no`. `RowError.message` — исходное сообщение без префикса `line N:`.
10. **`import_csv`** = `import_statement(path, store, strict=True, categorizer=..., clock=...).added`.
11. **Категоризация** — как раньше: `categorizer.categorize(tx)`, при результате — `dataclasses.replace`; `imported_at` берётся один раз из `clock.now()`.

## Risks / Trade-offs

- [Изменение поведения `import_csv`: дубли пропускаются, принимаются форматы «Сферы»] → описано в proposal; существующие тесты проходят без правок (ошибки строк по-прежнему `StatementError` с теми же `line_no`).
- [Мультимножество вместо множества для дублей — спорный момент для продакта] → решение принято и зафиксировано в спеке; смена — локальная правка.
- [Весь файл в памяти] → выписки малы; взамен проще атомарность.
- [Файл «Новы» с BOM теперь читается, раньше падал] → ожидаемо.
