## Why

Пользователи приносят выписки банка «Сфера» (два формата), а импорт умеет только «Нову». Текущий импорт к тому же хрупкий: повторный импорт задваивает операции, одна кривая строка роняет импорт посередине (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются. Задача LEDGER-58.

## What Changes

- Новый единый вход `import_statement` в `ledger/importer.py`: сам определяет формат (`nova`, `sfera`, `sfera_split`) по названиям колонок заголовка (без учёта регистра и краевых пробелов, в любом порядке; лишние колонки, например `Номер карты`, `Остаток`, игнорируются) и кодировку (UTF-8 с BOM или без / cp1251), возвращает `ImportResult` (формат, кодировка, `added`, `duplicates`, `errors`).
- Новые `detect_format` и `normalize_description` (последняя — то же сравнение описаний, что `rules.normalize_text`).
- Пропуск дублей (дата + сумма + нормализованное описание) относительно того, что уже в хранилище.
- Мусорные строки (пустые, из пробелов, из одних разделителей) пропускаются молча, где бы ни стояли.
- Кривые строки: в обычном режиме собираются в `errors`, остальное импортируется; при `strict=True` — `StatementRowError` на первой, в хранилище не попадает ничего (запись одной пачкой).
- Новые исключения `UnknownFormatError` и `StatementRowError` (наследники `StatementError`).
- `import_csv` сохраняет сигнатуру и возврат `int` (число добавленных), но делегирует в `import_statement` (автоопределение формата, `strict=True`). **Поведенческое отличие**: повторный импорт больше не задваивает операции, импорт атомарен, поддержаны BOM/cp1251, а форматы «Сферы» становятся доступны и CLI без правок `cli.py`.
- Не меняются: `ledger/cli.py`, `ledger/reports.py`, существующие тесты, публичный API `Transaction`/хранилищ/`Categorizer`. Только стандартная библиотека.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских выписок (форматы «Нова» и «Сфера»), определение формата и кодировки, дедупликация, обработка кривых и мусорных строк, атомарность strict-режима.
