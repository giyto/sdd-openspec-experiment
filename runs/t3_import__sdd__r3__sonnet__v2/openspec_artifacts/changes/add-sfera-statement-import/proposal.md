## Why

Пользователи приносят выписки банка «Сфера», а `import_csv` умеет только «Нову». Текущий импорт к тому же хрупкий: повторный импорт задваивает операции, кривая строка роняет импорт посреди файла (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются. Нужен единый вход, который сам определяет формат, не задваивает операции и честно сообщает о нечитаемых строках (LEDGER-58).

## What Changes

- Новый единый вход `import_statement(path, store, *, fmt, strict, categorizer, clock) -> ImportResult` и `detect_format(path)`: форматы `nova`, `sfera`, `sfera_split`.
- Определение формата по заголовку: колонки ищутся по названию без учёта регистра и краевых пробелов, порядок колонок и лишние колонки не важны.
- Кодировка: UTF-8 (с BOM или без), иначе cp1251.
- Дедупликация по (дата, сумма, нормализованное описание) относительно содержимого хранилища до импорта, с учётом количества.
- Мусорные строки (пустые, из пробелов, из одних разделителей) пропускаются молча.
- Некорректные строки собираются в `ImportResult.errors`; при `strict=True` первая такая строка бросает `StatementRowError`, и в хранилище не попадает ничего.
- Новые исключения `UnknownFormatError` и `StatementRowError` (наследники `StatementError`) и функция `normalize_description`.
- **Изменение поведения CLI `import`**: `import_csv` (сигнатура и `int` прежние) становится обёрткой над `import_statement(fmt="nova", strict=True)`. Повторный импорт не задваивает, BOM/cp1251 читаются, пустые строки пропускаются, импорт атомарен. `ledger/cli.py` и `ledger/reports.py` не меняются.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских выписок (`nova`, `sfera`, `sfera_split`): определение формата и кодировки, разбор строк, дедупликация, отчёт об ошибках, строгий атомарный режим, обёртка `import_csv`.

### Modified Capabilities

Нет: основных спеков в `openspec/specs` пока нет, поведение импорта «Новы» целиком описано в новой capability.

## Impact

- Код: `ledger/importer.py` (основное), `ledger/errors.py` (два класса); README (описание форматов).
- Публичный API `Transaction`, хранилищ, `Categorizer` не меняется; зависимости — только стандартная библиотека.
- Тесты: существующие не меняются, добавляются новые (`tests/test_statement_import.py`).
