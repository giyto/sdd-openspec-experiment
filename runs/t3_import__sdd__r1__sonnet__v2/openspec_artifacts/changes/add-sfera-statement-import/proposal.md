## Why

Пользователи приносят выписки банка «Сфера», а `import_csv` понимает только «Нову». Текущий
импорт к тому же хрупкий: повторный импорт задваивает операции, одна кривая строка роняет импорт
посреди файла (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются. См. LEDGER-58.

## What Changes

- Новая точка входа `import_statement(path, store, *, fmt, strict, categorizer, clock) -> ImportResult`
  в `ledger/importer.py` плюс `detect_format` и `normalize_description`.
- Поддержка форматов `nova`, `sfera` (`Дата;Сумма;Описание`) и `sfera_split`
  (`Дата;Описание;Приход;Расход`); формат определяется по заголовку (колонки «Сферы» ищутся по
  имени без учёта регистра и пробелов, лишние колонки игнорируются).
- Кодировка: UTF-8 (с BOM или без), иначе cp1251.
- Дедупликация относительно хранилища «до импорта» с учётом количества; одинаковые строки внутри
  файла дублями не считаются.
- Кривые строки собираются в `ImportResult.errors` (`RowError`), остальное импортируется;
  `strict=True` — `StatementRowError` на первой ошибке и ничего не записано.
- Мусорные (пустые, из пробелов, из одних разделителей) строки пропускаются молча.
- Новые исключения `UnknownFormatError` и `StatementRowError` в `ledger/errors.py`.
- `import_csv` становится обёрткой: строгий импорт `nova` через новый механизм, сигнатура и `int`
  прежние. **Поведенческое изменение:** повторный импорт больше не задваивает операции, пустые
  строки пропускаются, BOM/cp1251 читаются, ошибка в файле не оставляет частичной записи.
- `ledger/cli.py` и `ledger/reports.py` не меняются; существующие тесты не меняются.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских выписок (nova, sfera, sfera_split): определение формата и
  кодировки, разбор сумм и дат, дедупликация, отчёт об ошибках строк, строгий/нестрогий режим,
  атомарность, обёртка `import_csv`.

### Modified Capabilities

(нет: в `openspec/specs/` пока нет ни одной спецификации)

## Impact

- Код: `ledger/importer.py` (основной), `ledger/errors.py` (два класса); `README.md` (модули,
  форматы, соглашение о сравнении описаний).
- `ledger/rules.py`: только чтение — `normalize_description` делегирует `normalize_text`.
- Зависимости: только стандартная библиотека. Публичный API `Transaction`, хранилищ, `Categorizer`
  не меняется.
- CLI косвенно получает дедупликацию, BOM/cp1251 и атомарность через `import_csv`.
