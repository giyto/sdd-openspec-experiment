## Why

Пользователи приносят выписки банка «Сфера», а `ledger` читает только «Нову». Текущий `import_csv` к тому же хрупкий: повторный импорт задваивает операции, одна кривая строка обрывает импорт на середине (часть строк уже записана), файлы из Excel (UTF-8 с BOM) не читаются. Нужен единый вход импорта, который сам определяет формат, не задваивает операции, атомарен и честно сообщает о строках, которые не смог разобрать (LEDGER-58).

## What Changes

- Новый единый вход в `ledger/importer.py`:
  - `import_statement(path, store, *, fmt=None, strict=False, categorizer=None, clock=None) -> ImportResult`
  - `detect_format(path) -> str` (`"nova"` | `"sfera"` | `"sfera_split"`)
  - `normalize_description(text: str) -> str` — сравнение описаний для поиска дублей
  - `RowError(line_no, message)` и `ImportResult(format, encoding, added, duplicates, errors)` — frozen dataclass'ы
- Новые форматы «Сферы»: `sfera` (`Дата;Сумма;Описание`) и `sfera_split` (`Дата;Описание;Приход;Расход`); колонки ищутся по названию без учёта регистра и пробелов по краям, лишние колонки игнорируются.
- Определение кодировки: UTF-8 (BOM допустим), иначе cp1251.
- Дедупликация по (дата, сумма, нормализованное описание) относительно содержимого хранилища до импорта, с учётом количества.
- Пропуск мусорных строк (пустые, из пробелов, из одних разделителей) в любом месте файла.
- Нестрогий режим: кривые строки попадают в `ImportResult.errors`, остальное импортируется одной атомарной записью. Строгий режим (`strict=True`): первая ошибочная строка → `StatementRowError`, в хранилище ничего не попадает.
- `ledger/errors.py`: `UnknownFormatError` и `StatementRowError`, оба наследуют `StatementError`.
- `import_csv(path, store, categorizer=None, clock=None) -> int` сохраняет сигнатуру и тип результата, но становится обёрткой: строгий импорт формата `nova` через `import_statement` (дедупликация, BOM/cp1251, пропуск пустых строк, атомарность).
- **Изменение поведения `import_csv`/CLI**: повторный импорт ничего не добавляет, а ошибка в строке больше не оставляет частично записанных данных.

## Capabilities

### New Capabilities
- `statement-import`: импорт банковских выписок («Нова», «Сфера», «Сфера» split) — определение формата и кодировки, разбор строк, дедупликация, обработка ошибок, атомарность, совместимая обёртка `import_csv`.

## Impact

- Код: `ledger/importer.py` (основная работа), `ledger/errors.py` (два класса); README (описание форматов и модуля).
- Не затрагиваются: `ledger/cli.py`, `ledger/reports.py`, публичный API `Transaction`, хранилищ и `Categorizer`; новых зависимостей нет (только стандартная библиотека).
- Существующие тесты не меняются; добавляются новые тесты импорта.
- CLI получает дедупликацию и атомарность через `import_csv` без правок кода CLI.
