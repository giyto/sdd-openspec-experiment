## Why

Пользователи приносят выписки банка «Сфера», а импорт умеет только «Нову». Текущий
импорт также хрупкий: повторный импорт задваивает операции, кривая строка роняет импорт
на середине (часть строк уже записана), файлы, сохранённые из Excel (UTF-8 с BOM) и в
cp1251, не читаются. Нужен один вход для импорта, который сам определяет формат, не
задваивает операции и честно сообщает о строках, которые не смог разобрать (LEDGER-58).

## What Changes

- Новая функция `import_statement(path, store, *, fmt=None, strict=False, categorizer=None, clock=None) -> ImportResult`
  с автоопределением формата по заголовку (`nova`, `sfera`, `sfera_split`) и кодировки (UTF-8 с BOM или без, иначе cp1251).
- Формат `sfera`: `Дата;Сумма;Описание`, суммы с пробелом-разделителем тысяч (в том числе U+00A0), запятой
  и знаком (приход без знака или с `+`).
- Формат `sfera_split`: `Дата;Описание;Приход;Расход`, суммы без знака, заполнена ровно одна из двух колонок,
  расход становится отрицательной суммой.
- Дедупликация с хранилищем по дате, сумме и `normalize_description` с учётом количества: если в хранилище k
  совпадающих транзакций, а в файле n, то первые min(k, n) строк — дубли. Дубли внутри самого файла дублями не считаются.
- Построчная обработка ошибок: ошибочные строки попадают в `ImportResult.errors` с `line_no`, остальные импортируются.
  Режим `strict=True` прерывает импорт на первой ошибочной строке (`StatementRowError`) без записи чего-либо.
- Пустые и «мусорные» строки (пустые, из пробелов, из одних разделителей) пропускаются и не считаются ни ошибкой,
  ни дублем, ни добавленной транзакцией.
- Новые исключения в `ledger/errors.py`: `UnknownFormatError` и `StatementRowError`, оба наследуют `StatementError`.
- Новая функция `detect_format(path) -> str` и `normalize_description(text) -> str` (делегирует `rules.normalize_text`).
- `import_csv(path, store, categorizer=None, clock=None) -> int` становится обёрткой над `import_statement`
  с `fmt="nova"` и `strict=True`: сигнатура и возвращаемое `int` прежние, поведение — дедупликация, BOM/cp1251,
  пропуск пустых строк и атомарность. CLI (`ledger/cli.py`) не меняется и получает новое поведение через `import_csv`.

**BREAKING** (для вызывающего кода `import_csv`): при ошибке строки файл больше не импортируется частично —
выбрасывается `StatementRowError` и ничего не записывается; повторный импорт не задваивает операции.

## Capabilities

### New Capabilities
- `statement-import`: разбор банковских выписок («Нова», «Сфера», «Сфера» с раздельными колонками прихода и расхода),
  определение формата и кодировки, дедупликация с хранилищем, построчная обработка ошибок и атомарность записи.

## Impact

- Код: `ledger/importer.py` (основная переработка), `ledger/errors.py` (два новых исключения).
- Без изменений: `ledger/cli.py`, `ledger/reports.py`, `Transaction`, хранилища и `Categorizer` (публичный API не ломается).
- Тесты: существующие тесты не меняются; добавляются новые тесты импорта.
- Зависимости: только стандартная библиотека.
