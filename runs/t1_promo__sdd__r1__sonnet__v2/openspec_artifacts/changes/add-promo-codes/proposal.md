## Why

Маркетинг запускает летнюю кампанию с промокодами (SHOP-412). Сейчас скидки вручную делает поддержка, и суммы расходятся с чеками. Бухгалтерия считает налог по строкам, поэтому скидка должна быть видна и в итогах заказа, и построчно.

## What Changes

- Новая модель промокода (процентный / на фиксированную сумму) и реестр промокодов с часами, сроком действия, лимитом использований и счётчиком использований.
- Три новых независимых исключения под общим `PromoError`: неизвестный код, код вне срока (включая «ещё не начался»), нарушены условия (лимит исчерпан или заказ не подходит).
- `calculate_total` принимает необязательный промокод; скидка раскладывается по участвующим строкам (метод наибольшего остатка, в копейках), налог строки считается с суммы после скидки, порог бесплатной доставки сравнивается с суммой товаров после скидки.
- В `LineTotal` и `OrderTotal` появляется поле `discount`; `total = subtotal - discount + shipping + tax`.
- `OrderService.quote` / `place_order` принимают строковый `promo_code`; пустая строка или пробелы означают «без промокода». Использование считается только при успешном `place_order`.
- `OrderService.cancel` возвращает использование промокода (счётчик −1).
- `Order.promo_code` хранит нормализованный код или `None`.
- Обратная совместимость: все старые вызовы и их суммы не меняются. `shop/cli.py`, `shop/reports.py` и существующие тесты не трогаем.

## Capabilities

### New Capabilities
- `promo-codes`: описание промокода, его валидация, нормализация кода, реестр, проверки существования / срока / лимита, учёт использований.
- `promo-pricing`: влияние промокода на расчёт итогов: участвующие строки, процент и фиксированная сумма, раскладка по строкам, налог, доставка, условия заказа.
- `promo-orders`: передача кода в `quote` / `place_order`, пустой код, порядок проверок, учёт использований при оформлении и возврат при отмене.

## Impact

- Код: новый `shop/promo.py`; изменения в `shop/errors.py`, `shop/pricing.py`, `shop/orders.py` (и, по соглашению пакета, экспорт в `shop/__init__.py`).
- Тесты: только новые файлы в `tests/`.
- README: добавить правило скидок в «Правила расчёта» (при реализации).
- Зависимости: новых нет. Публичные сигнатуры расширяются только необязательными аргументами со значениями по умолчанию.
