# ledger

Небольшая библиотека и CLI для учёта личных финансов: транзакции, правила
категоризации, импорт банковских выписок, месячные отчёты.

## Структура

| Модуль               | Что внутри                                                        |
|----------------------|-------------------------------------------------------------------|
| `ledger/models.py`   | `Transaction` (frozen dataclass) и деньги: `to_money`, `parse_amount`, `format_amount` |
| `ledger/errors.py`   | иерархия исключений проекта (всё наследуется от `LedgerError`)    |
| `ledger/clock.py`    | часы: `Clock`, `SystemClock`, `FixedClock`                        |
| `ledger/storage.py`  | хранилища `MemoryStore` и `JsonFileStore`                         |
| `ledger/rules.py`    | правила категоризации `Rule`, `Categorizer`, `load_rules`         |
| `ledger/importer.py` | импорт выписок «Новы» и «Сферы» (`import_statement`, `import_csv`) |
| `ledger/reports.py`  | месячные сводки по категориям                                     |
| `ledger/cli.py`      | командная строка (`python -m ledger ...`)                         |

## Соглашения

- **Деньги — только `Decimal`**, два знака после запятой (`models.CENT`). `float` в
  суммах запрещён: `Transaction` бросит `ValidationError`. Расход — отрицательная
  сумма, приход — положительная. Нулевая сумма недопустима.
- **Исключения** — только из `ledger.errors`. Ошибки разбора выписки —
  `StatementError` с атрибутом `line_no` (номер физической строки файла, заголовок —
  строка 1; подробности в докстринге `StatementError`).
- **Сравнение описаний** — только через `rules.normalize_text` (пробелы, регистр, ё/е);
  хранится описание как пришло, без нормализации.
- **Время** — никаких `datetime.now()` в бизнес-коде: часы передаются параметром
  `clock` (по умолчанию `SystemClock`). В тестах — `FixedClock`.
- **Логирование** — модульный логгер `logger = logging.getLogger(__name__)`, без `print`
  (кроме `cli.py`).
- **Модели** — `@dataclass(frozen=True)`; изменение через `dataclasses.replace`.
- **Хранилище**: `add` добавляет одну транзакцию, `add_many` — пачку целиком
  (сначала все проверяются, затем одна запись на диск). Идентификаторы назначает хранилище.

## Формат выписки «Нова»

```
date,amount,description
2026-03-01,-350.00,Кофейня Зерно
2026-03-02,85000.00,Зарплата
```

Разделитель `,`, дата ISO `ГГГГ-ММ-ДД`, сумма с точкой и знаком, кодировка UTF-8.

## Форматы «Сферы»

`sfera` — `Дата;Сумма;Описание`, `sfera_split` — `Дата;Описание;Приход;Расход`.
Разделитель `;`, дата `ДД.ММ.ГГГГ`, десятичная запятая, тысячи через пробел/U+00A0.
`import_statement` сам определяет формат и кодировку (UTF-8, UTF-8 с BOM, cp1251),
пропускает уже импортированные транзакции и собирает ошибки строк в `ImportResult`;
`strict=True` — атомарный импорт с `StatementRowError` на первой ошибке.
