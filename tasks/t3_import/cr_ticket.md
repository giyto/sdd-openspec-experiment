# LEDGER-74: доработки импорта выписок после первого месяца

## Зачем

Импорт выписок из LEDGER-58 работает уже месяц, и за это время накопилось три вещи. «Сфера»
обновила формат выгрузки. Интерфейсу импорта нужно превью до сохранения и сами строки с
ошибками, чтобы показать их пользователю. А поддержка жалуется на строгий режим: исправляешь
одну строку, запускаешь снова и получаешь следующую.

## Что меняем

1. Раньше договорились, что точка в сумме «Сферы» — ошибка строки. Новая выгрузка банка пишет
   суммы с точкой (`-1 234.56`), старая — с запятой. Теперь в обоих форматах «Сферы» принимаем
   оба десятичных разделителя. Если в сумме есть и точка, и запятая, это ошибка строки.
2. В `sfera_split` строка с нулями в обеих колонках раньше была ошибкой. Оказалось, что так
   банк помечает служебные операции (блокировки), поэтому такие строки теперь молча пропускаем:
   это не ошибка, не дубль и не добавленная транзакция.
3. Описание при импорте теперь сохраняем без лишних пробелов: по краям обрезаем, несколько
   пробелов подряд внутри заменяем одним. Регистр и буквы не трогаем.
4. Строгий режим раньше останавливался на первой ошибочной строке. Теперь он разбирает файл до
   конца и бросает `StatementRowError` со всеми ошибками; `line_no` и сообщение берутся у первой.
   Атомарность прежняя: из файла в хранилище не попадает ничего.

## Новое

```python
# ledger/importer.py
def import_statement(path, store, *, fmt=None, strict=False,
                     categorizer=None, clock=None, dry_run=False) -> ImportResult: ...

@dataclass(frozen=True)
class RowError:
    line_no: int
    message: str
    raw: str = ""                      # исходный текст записи из файла

@dataclass(frozen=True)
class ImportResult:
    ...                                # прежние поля без изменений
    transactions: list[Transaction] = field(default_factory=list)

# ledger/errors.py
class StatementRowError(StatementError):
    errors: list[RowError]             # все ошибки строк файла по порядку
```

5. `dry_run=True` — превью: считаем всё так же, как при обычном импорте, но в хранилище ничего
   не пишем.
6. `ImportResult.transactions` — добавленные транзакции в порядке строк файла, с `id`, которые
   назначило хранилище.
7. `RowError.raw` — текст записи так, как он стоит в файле, без перевода строки в конце. Если
   запись занимает несколько строк файла, они соединяются через `\n`.

## Рамки

Как в LEDGER-58: `ledger/cli.py`, `ledger/reports.py` и существующие тесты проекта не трогаем,
используем только стандартную библиотеку. Старые вызовы `import_statement` и `import_csv` должны
работать как раньше, кроме пунктов 1–4. Тесты, которые проверяли прежнее поведение этих пунктов,
обновить.
