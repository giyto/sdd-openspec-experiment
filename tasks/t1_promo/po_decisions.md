# Решения владельца продукта по SHOP-412 (промокоды)

Эти решения знает только владелец продукта, в тикете их нет.

**D1. Минимальная сумма заказа.** В минимальную сумму идут только товары, на которые скидка реально
действует. Подарочные сертификаты и категории, исключённые для этого кода, не считаются. Сумма
берётся до скидки, без доставки и налога. Если сумма ровно равна минимальной, код подходит.

**D2. В корзине нет ни одного товара, на который действует скидка** (например, только
сертификаты). Тогда код не применяется, и покупатель получает ошибку «условия промокода не
выполнены». Так происходит, даже если у кода нет минимальной суммы. Тихо принимать код с нулевой
скидкой нельзя.

**D3. Как делить скидку по строкам чека.** Каждая участвующая строка получает долю скидки,
пропорциональную своей сумме (цена × количество). Долю округляем вниз до копейки. Копейки, которые
остались после округления, раздаём по одной тем строкам, у которых при округлении отбросили больше
всего. Если отброшено поровну, копейку получает строка, которая выше в чеке (раньше попала в
корзину). Неучаствующие строки получают 0.

**D4. Порог бесплатной доставки** сравниваем с суммой товаров уже после скидки. Иначе люди добирают
до порога промокодом. Саму стоимость доставки скидка не уменьшает.

**D5. Отмена заказа.** Если заказ с промокодом отменили, использование промокода возвращается:
счётчик уменьшается на один. Тогда поддержка может переоформить клиенту заказ с лимитированным кодом.
